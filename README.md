# ROES

- `be/` back end (Bun, Hono, Sequelize, MySQL)
- `fe/` mayor website (Next.js)
- `apk/` mobile app (Expo)

Start `be` first (see `be/README.md`), then `fe` and `apk`. The mayor signs in with the `MAYOR_EMAIL` / `MAYOR_PASSWORD` from `be/.env`; the mayor creates places and admins, and residents register in the app.
